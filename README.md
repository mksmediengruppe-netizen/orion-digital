# ARCANE 4.0 — AI-Агентство Полного Цикла

ARCANE 4.0 — операционная система AI-агентства, которая заменяет 25-30 специалистов:
разработчиков, дизайнеров, маркетологов, копирайтеров, SEO-специалистов и менеджеров.

## Архитектура: Мозг + Руки

**Мозг (планирование и стратегия):**
- **Director** = Claude Opus 4.6 — думает, планирует, делегирует
- **Art Director** = Claude Opus 4.6 — визуальная концепция мирового уровня
- **Marketer** = Claude Opus 4.6 — позиционирование, ЦА, стратегия
- **Writer** = Claude Opus 4.6 — тексты которые продают
- **SEO Writer** = Claude Sonnet 4.6 — SEO-архитектура, ключевые слова
- **Developer** = Claude Sonnet 4.6 — лучший код (SWE-bench 79.6)
- **QA** = GPT-5.4 — независимый code review (другая семья = другие глаза)
- **Researcher** = Gemini 3.1 Pro — анализ рынка (1M контекст)

**Руки (исполнение):**
- **Manus** — ЕДИНСТВЕННЫЙ кто трогает сервер, браузер, деплой, visual QA

- Сайты и лендинги (Awwwards-уровень)

- Маркетинговые стратегии и контент-планы
